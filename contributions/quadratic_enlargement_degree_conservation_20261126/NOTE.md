# Actual quadratic enlargement: degree conservation and exact merger census

## Claim

Lean-verified partial result: for the actual map f(z)=z²+c, an enlarged connected pullback component over V and an open connected U contained in V, one inverse fiber over any y in U enumerates precisely the old components contained in the enlargement. The census is independent of y, even at postcritical values. The old component fiber cardinalities sum to the enlarged fiber cardinality; for regular y this is exactly 2^R, the intrinsic reflection-rank degree of the enlarged component. Any declared subfamily of the actual components exhausts the enlargement if and only if its summed mass reaches this number (or the enlarged distinct-point count at critical y). Equal old rank d gives exact merger count times 2^d = 2^R. Neither target is required to be simply connected.

### Source-facing consequence and remaining test

For a specified typed base U and a selected enlarged component B, a declared finite geometric family need not assume component ownership: each nonempty connected open piece must lie in B and its restriction of the same actual polynomial iterate to U must be proper. The theorem `proper_piece_mem_mergerCensus` derives component ownership. Then `proper_piece_family_eq_census` tests completeness by a single inverse-fiber mass equality, even at a critical target; `mergerCensus_unique_connected_image` supplies uniqueness of the actual address of any nonempty connected reached subset in the old pullback inside B. The regular-fiber criterion requires a regular anchor if one substitutes intrinsic degree for distinct-point mass. For a certified univalent old family, every regular-fiber contribution is one, while a ramified reached component contributes more; this is precisely why the native [residual-clock audit](../../research/independent_audits/virtual-reached-clock_20261126/NOTE.md) cannot be repaired by counting symbolic labels alone. No source-level certificate asserting that the actual virtual demand family satisfies these hypotheses is supplied here.

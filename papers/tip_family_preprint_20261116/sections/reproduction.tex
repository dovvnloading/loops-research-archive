\subsection{Why arithmetic is rigorous}
The main finite
primitive-root
packets have
\emph{adjacent}
dyadic endpoints
of denominator
$2^{256}$, obtained
from explicit
rational seeds and
sign bisection.
Every polynomial
interval evaluation
and derivative
uses a fixed
integer grid
$S=2^{512}$:
a rational lower
value is rounded
by \emph{floor}
and an upper
value by
\emph{ceiling}.
For interval
addition and
multiplication,
the four
endpoint products
are enclosed
with the same
outward rule;
interval squaring
explicitly uses
zero whenever
the input
straddles zero.
Inclusion
follows inductively
under each
polynomial
operation.
This works
equally for a
full complex
disk when
combined with
the analytic
majorant
recurrence
\eqref{eq:tail}.
The third-return
finite tail
uses a separately
outward $2^{-192}$
upper grid.
The original
crest checker
uses a $384$-bit
outward rational
interval grid
and $512$
\emph{whole}
radius bins,
with independent
bisection and
strict angular
monotonicity,
not floating
point quadrature.

For transcendental
bounds, Machin's
identity
$\pi=16\arctan(1/5)
-4\arctan(1/239)$
and rational
alternating arctangent
remainders give
certified $\pi$
brackets.
For positive
$x$ in the
specified domains
the atanh series
\[
 \log x=2\sum_{j=0}^{N-1}
 \frac{u^{2j+1}}{2j+1}
 +\mathcal{R}_N,\qquad
 u=\frac{x-1}{x+1},\quad
 |\mathcal{R}_N|\le
 \frac{2|u|^{2N+1}}
 {(2N+1)(1-u^2)}
\]
and alternating
trigonometric
Taylor bounds
give rational
enclosures for
logs, trigonometric
and inverse
trigonometric
functions.
The elliptic
$K(k)$ ratios
are enclosed by
outward rational
AGM or equivalent
power-series
bounds, with
explicit tails.
Every numerical
entry in a
strict theorem
is thus a
rational
inequality;
any human-readable
decimal endpoint
is a \emph{literal
rational number},
not a machine
float or a
measured approximation.
The all-$p$
tail steps
prove the
universal
monotonicity
or nested-box
property and
check its
worst $p=13$
or $p=17$
case by
rational
arithmetic.
They are
\emph{not}
finite sampling
extrapolations.

The proof
and code
trust boundary
is important.
KKL definitions
and Lemma A.11
\cite{KKL2026};
Douady--Hubbard's
straightening
\cite{DH1985};
McMullen's
almost-disjointness
\cite{McMullen1994};
the Misiurewicz
dendrite theorem
\cite{LyubichNotes};
Carath\'eodory's
extension
\cite{Caratheodory1913};
SC and
Riemann--Hurwitz
\cite{AhlforsInvariants,Forster1981}
are imported
\emph{by theorem
and explicit
hypotheses},
not certified
by Python or
the existing
finite Lean
incidence
models.
No novel
classical
theorem is
secretly
encoded as
a numeric
test.

## 2. What exactly fails in the original proof

The exact mathematical displays in KKL v1 (H:1373–1400, 1749–1753; PDF pp. 49–50, 64) are:

    (6.25) W(A_n \ A_{n+1}) = O(1), 0 <= n < N-1.
    (6.26) W(S_n) <= W(X_n) + O(1).
    (6.29) W(A_n \ A'_{n+1}) <= W(S_{n+1} \ X_{n+1}) + O(1).
    (6.30) W(A^{N-ubr}) <= W(A^sh) + W(A_{N-1}) + O(b).
    A.13: W(A') <= W(A) + O(1+log d).

A.13 assumes a Wave A' in (V', f^*I) ending at multi-interval I', with f of degree at most d on I'; it asserts a Wave A contained in f_*A'. It neither assumes the DL common interval nor asserts absence of short leaves or bounds the width of a discarded source complement. See [KKL v1 §6](https://arxiv.org/html/2606.27272v1#S6) and [Appendix A](https://arxiv.org/html/2606.27272v1#A1). The formulas above are transcribed, not corrected.

KKL H:1373–1385, (6.25)–(6.26) (p. 49): fix b and N=b+3, a Wave A ending at the critical limb block L_0, put A_0=A^{N-ubr} minus A^sh, and inductively take nested maximal subwaves with central-ending outputs S_n=F_*^n A_n. Here S_n is (N-n)-unbreakable. The only explicit A.13 invocation in the proof of 6.24 is H:1383, to extract X_n from F_* S_n, allegedly nonshort with W(S_n) <= W(X_n)+O(1). The implicit cover input would be the filtered immersion restriction of S_n, not S_n itself.

KKL A.1, H:1563–1567 (p. 56), distinguishes ending at a marked block (one endpoint of each leaf there) from cresting over a block (in the base outside its ends). DL 5.2, H:1265–1266,1274–1279, instead requires a single interval J on one annular boundary component lying on the bounded side of *every* input leaf; the endpoints must avoid J. No common J is supplied at H:1383. Neither the degree-two cover, central ending nor set-valued unbreakability alone supplies this certification; the last is about the number of distinct untagged outputs, not occurrence multiplicity. The existing [full-lift counterexample](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/qa_extremal_wave_2026-07-26.md#L587-L704) and its [distinction from the DL theorem](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/qa_extremal_wave_2026-07-26.md#L939-L985) refute broad A.13, but are not an actual native F satisfying 6.24's hypotheses. See the earlier [source audit of this invocation](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/qa_native_kkl_stationary_2026-07-26.md#L257-L373).

Second, (6.29) (p. 50; H:1389–1397) is not a relative discard estimate supplied by (6.26). Subadditivity W(U union V) <= W(U)+W(V) does not permit subtracting retained widths to upper-bound W(U minus V). Nor does an untagged output difference bound the width of lost input occurrences with coefficient one. Even changing the mismatched prime/index at H:1389 and replacing S_{n+1} with X_n in (6.29) does not provide the necessary relative estimate. The [earlier detailed audit](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/qa_native_kkl_stationary_2026-07-26.md#L374-L539) identified these exact gaps. ## 3. Conditional repaired statement for the preliminary telescope

Subject to the native analytic/Borel inputs of N1, in the native stationary setting (fixed parabolic bound b>=1; rotation 1/q; periodically repelling primitive pseudo-quadratic-like relation; proper Wave A ending at L_0), put N=b+3. The archived N1 construction claims the existence of nested proper Borel subwaves A_0,...,A_{N-1} with the prescribed A_0 and S_n=F_*^n A_n central-ending and (N-n)-unbreakable, and a C_b independent of q, the Wave and all analytic widths, for which

    W(A_n minus A_{n+1}) <= C_b,  0 <= n < N-1.                  (R)

An empty core is allowed. For n>=1 each nonempty S_n also has one common *leafwise* noncritical limb direction, so it has no short leaves. This is [Theorem N1, lines 35–76](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L35-L76); its mathematical hypotheses match the stationary native situation of KKL H:537–548, 1181–1204, 1248, 1364–1383. KKL H:548 fixes b throughout these sections; hence O_b(1) is the intended notion of a uniform constant, not an absolute estimate simultaneously uniform as b tends to infinity. The proof is summarized below with explicit imports and derivation of (R).

### 3.1. The correct DL input, once per directed packet

Notation: V=U minus T, V'=U' minus f^{-1}(T); f:V' -> V is a degree-two holomorphic annular cover, iota:V' -> V the immersion. Work on their prime-end compactifications; do not identify an ideal marking with physical boundary points. KKL Prop. 6.5, 6.6 and the immediately following action rule, H:1189–1204, prove the pullback of a connected limb block I is one interval J=iota^*I and the action shifts L_j to L_{j+1} for j!=0, while L_0 maps onto the whole inner boundary. Both path filters are from A.3.2, H:1713–1715. KKL 6.10 proof, H:1295–1298 and 1314, supplies the unbreakable restriction type; A.11 (H:1708–1712) supplies domination.

Write S ↑ I if the singleton crest of every leaf of S contains the same connected I. Unlike an aggregate crest or an ending block this is a leafwise predicate. By [N1 Lemma 4.1, lines 583–694](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L583-L694), for S unbreakable and S ↑ I, take B=B_I(S) to contain all surviving directed occurrences over J=iota^*I. It is a disjoint proper Wave above that *one* J, with at least one occurrence of each parent. The proof uses the singleton restriction classified above, then the marked-circle directionalization argument: a connected J in the aggregate crest avoids both endpoint intervals; each boundary-side route either contains J or avoids it, and if every route avoided J the union would be subordinate to the circle minus a closed marked interval in J, contradicting minimality of the aggregate base. Thus at least one actual directed occurrence exists, without selecting one arbitrarily. Unbreakability gives a unique untagged successor but possibly two retained occurrences. See the [separate directionalization audit](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_n1_degree_two_directionalization_audit_20260726.md#L69-L242). If the singleton restriction and marked-circle lemma apply, this supplies the exact DL 5.2 common-interval hypothesis for each repaired invocation, not for the whole original S_n. The restriction is not asserted to be an embedding.

The archive uses DL 5.2's **proof**, not the aggregate retained-width statement: H:1280–1302, Feigen.tex 2827–2841. It discards O(log m) deck-span packets, each bounded in width by the Shift argument, and one bounded outer buffer. On the finite-area round annulus first discard the Borel infinite-length family (width zero by constant epsilon densities), preserving the common-J hypothesis on the rectifiable core. If the final deletion has the asserted bounded buffer width in the native rectifiable packet, the Parallel Law gives total source discard width O(1+log m); here m=2. The quantitative buffer interpretation and rectifiable scope are checked in the [final integration proof, lines 115–240](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_n1_integration_audit_20260726.md#L115-L240); the ledger imports precisely this native estimate, not a subtraction from the displayed DL inequality. The rejected additivity approach is not used [integration lines 241–269](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_n1_integration_audit_20260726.md#L241-L269).

If necessary enlarge the discarded family to a Borel super-discard at cost at most 1 using [Borel width envelope, Thm. 1.1](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_n1_borel_width_envelope_20260726.md#L45-L97) and its [proof](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_n1_borel_width_envelope_20260726.md#L413-L522). ### 3.2. Conditional directed bounds and initial split

If S ↑ L_0 and is one-step unbreakable, a retained singleton would, by A.14, crest over F_*L_0, the entire inner component. This is impossible for a proper path with ends outside the crest. Thus B^sharp is empty and W(S)<=c_DL. This is [N1 Lemma 4.2](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L696-L746), a replacement for the critical bound in 6.21, requiring no broad A.13. For a two-step-unbreakable S ↑ L_{q-1}, the output of the retained packet is directed over L_0 and still one-step unbreakable; W(S)<=c_DL+2c_DL=3c_DL by the preceding estimate and full-lift bound. [N1 Lemma 4.3](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L748-L794).

Every nonshort central-ending singleton has a crest containing some noncritical limb. In the cyclic order of the connected, noninterleaving limb blocks, its boundary-side route from a central end to that limb must pass completely through an adjacent limb L_1 or L_{q-1}. Partition the leaves by the first alternative (give it priority if both hold); the remainder has the second. This is [N1 Lemmas 5.1–5.3](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L800-L966). For q=2 the two coincide and the entire initial family has bounded width. For q>2, the negative-direction class has width <=3c_DL and only the positive-direction packet is continued. Do not union two pushed packets or assume that the union of their crests is a common crest. The initial family is indeed nonshort leafwise because the maximal short subwave is exactly the family of individually short leaves (KKL H:1146–1147; N1 lines 935–955).

### 3.3. Conditional relative one-step loss (not retained-width subtraction)

For a central-ending S ↑ L_k, k!=0, with at least two unbreakable steps left, use §3.1. The retained output R ↑ L_{k+1} (indices mod q), with at least one unbreakable step left. If k+1=0 mod q, its width is <=c_DL and we can take the next core empty, at total cost <=3c_DL.

Otherwise localize S by its endpoint in L_0, at most 6b marked intervals. The n=1 proof of KKL Lemma 6.14, H:1278–1286 (p. 45), yields one leafwise critical-over module and at most eta_b=6b+4b(2b+1) localized modules for R. This is not an application of the n>1 statement or A.13. Allocate modules disjointly, then partition R into C (central endpoints), Y (remaining leaves over L_0) and localized Z_r (the rest). A residual singleton's connected base must avoid L_0: without a central endpoint, an intersection with that block would contain the whole block and put the leaf in Y. Every residual leaf is nonshort since all of R has the same noncritical direction. The critical bound above and KKL Prop. 6.22, H:1354–1362 (p. 49), whose proof uses A.15 alone, give

    W(R minus C) <= c_crit + eta_b c_away = e_b.

Full proof: [N1 Lemmas 6.1–6.3](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L969-L1139). Define P_C to be the full parent saturation of C under the unique untagged successor Phi_1. Parents of S outside P_C either have no retained directed occurrence, in which case each has an occurrence in the bounded Borel discard, or have a retained directed occurrence, in which case all retained occurrences map outside C into E=R minus C. The former family is dominated by the discarded B-family, the latter by the full degree-two lifts of E. Thus

    W(S minus P_C) <= c_DL + 2W(E) <= c_DL + 2e_b.

In the critical-wrap case use e_b replaced by c_crit. Each output leaf of C has a retained parent, and saturation gives Phi_1(P_C)=C exactly. This proves [N1 Proposition 7.1, lines 1156–1331](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L1156-L1331), with c_step=c_DL+2 max(c_crit,e_b). In particular the cost is paid once per packet, not once per arc class, not once per sheet, and not once per q. For the initial step, full saturation across both original directions can only reduce the discard; it preserves the same central target. Thus c_init=3c_DL+c_step works by [N1 Prop. 8.1](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L1335-L1418).

### 3.4. Stationary induction and telescope, assuming the packet estimates

Let Phi_n denote the unique untagged n-step successor on the initial unbreakable leaves, with Phi_{n+1}=Phi_1 composed with Phi_n. The [retained-chain theorem](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_retained_realization_source_audit.md#L312-L387) establishes one retained proper occurrence at each step and the common output, not uniqueness of lifts or a two-path separator. For n>=1 choose the P_{C,n} above inside S_n, and set

    A_{n+1} = A_n intersect Phi_n^{-1}(P_{C,n}).
    S_{n+1} = Phi_{n+1}(A_{n+1}) = C_{n+1}.

The equality is by full saturation: every element of P_{C,n} has a preimage in A_n, and every retained input maps into that packet. In particular the lost family D_n=A_n minus A_{n+1} has Phi_n(D_n) contained in S_n minus P_{C,n}; it cannot contain a parent of a retained output merely because a different occurrence was removed. For any D contained in A_n, each earlier Phi_j(D) is contained in the already constructed Wave S_j. A.11 domination into all retained restrictions and the full-lift bound give

    W(Phi_j(D)) <= 2 W(Phi_{j+1}(D)), 0 <= j < n.
    W(D_n) <= 2^n W(S_n minus P_{C,n}) <= 2^{b+1} c_step.

This is [N1 Lemma 2.2](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L249-L295) and [§9, equations (9.5)–(9.13)](https://github.com/dovvnloading/loops-research-archive/blob/9f39af35723e1ebe8f94963f1dbd71d54d4309a9/research/mlc_unified/kkl_stationary_relative_wave_continuation.md#L1420-L1567). At n=0 use c_init instead. All constants are independent of q and widths, so take C_b=max(c_init,2^{b+1}c_step). The last transition is n=N-2, with two steps left at source and one at target; no A_N or extra iteration is assumed. If a direction wraps into L_0, the next core is empty and all subsequent cores are empty. This is (R).

The Parallel Law now gives, with exactly the same original A_0,

    W(A^{N-ubr}) <= W(A^sh)+ W(A_0)
                 <= W(A^sh)+ W(A_{N-1})+(N-1) C_b.

This conditionally supplies the replacement of (6.30), H:1399–1400, p. 50. No equality of widths of disjoint families is used.

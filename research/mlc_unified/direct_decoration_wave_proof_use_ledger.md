### 3.2 Conditional arithmetic after a growth lemma

The source sets \(N_b=216b^2\).  If
\[
  A_1,\ldots,A_{N_b}
\]
were a forbidden visit chain with crests \(I_r\), and if the still-open
combinatorial-growth step supplied
\[
   \ell(I_{n+18b})>\ell(I_n)
   \qquad(1\le n\le N_b-18b).
   \tag{3.1}
\]
Use the indices
\[
  1,\ 1+18b,\ \ldots,\
  1+(12b-1)18b.
  \tag{3.2}
\]

\(\ell(I_1)\ge1\), the last length is at least
\[
  1+(12b-1)=12b,

repairs only the arithmetic after the growth implication; it does not
prove that implication.

The source proof of the preceding growth proposition has two independent

## 4. Definition of the target-first ledger

Fix:

1. a parabolically \(b\)-bounded, primitively renormalizable,
   periodically repelling pseudo-quadratic-like map
   \(F=(f,\iota)\);
2. all finite choices made by one KKL dichotomy execution (a typical
   interval in the tame branch, or the waves and witnessed iterate words
   in the Wave branch); and
3. the explicitly declared repair readings N1--N10.

This collection is denoted by \(\mathfrak e\).
It is an input to the compiler.  Nothing in this definition proves that
the direct-decoration program canonically supplies such an
\(\mathfrak e\), that its native assertions are true, or that it is
aligned with KL stages.

### 4.1 Stage set

The stage set \(\mathcal H(F,\mathfrak e)\) contains:

- the tree-complement one-step pair
  \[
     (f,\iota):
     U^1\setminus T^1\rightrightarrows U\setminus T;
  \]
- every witnessed tree-complement iterate
  \[
     (f^n,\iota_n):
     U^n\setminus T^n\rightrightarrows U\setminus T;
  \]
- the small-Julia full return
  \[
     (f^p,\iota_p):
     U^p\setminus\mathcal K^p
       \rightrightarrows U\setminus\mathcal K;
  \]
- the inner and outer translation-marking lifts;
- for the selected tame interval \(I\), the localization cover
  \[
     g:\widehat V_I\longrightarrow V_I
  \]
  and the separately typed localization immersion
  \[
     i:\widehat V_I\setminus\widehat{\mathcal K}_I
       \longrightarrow V_I\setminus\mathcal K_I;
  \]
- the finite Hubbard-tree/Value model used for the full return; and
- the proper map and compact-set package used by the Wanderers call.

Repeated uses of the same analytic map with different target families
remain different ledger rows.  Conversely, a different symbol does not
create a new stage if source normalization proves it is the same map.

### 4.2 Row type

A proof-use row is
\[
\begin{split}
\mathcal Q=(&q,\ {\rm source},\ {\rm lines},\
V_t,\mathcal I_t,\Gamma_t,\mathcal E_t,\
\mathcal H_q,\\
&{\rm constructor},\ {\rm universal\ query},\
{\rm filters},\ {\rm degree/route\ word},\
{\rm downstream\ use},\ {\rm last\ use}).
\end{split}
\tag{4.1}
\]

Formally, this displayed record is encoded in a finite many-sorted token
set.  The sorts are
\[
\begin{gathered}
 {\sf Source,\ Stage,\ Map,\ Word,\ Marking,\ Interval,\ End,}\\
 {\sf TargetFamily,\ KKLQuery,\ WADQuery,\ AnalyticCall,\ RootRecord}.
\end{gathered}
\tag{4.2}
\]
A target family such as "every proper target path in \(\Gamma\)" is one
**intensional binder token**, namely the alpha-equivalence class of the
corresponding formula with its bound path variable.  It is not one token
per geometric path.  Conjunctive hypotheses of a theorem call are stored
as a typed joint-certificate node, so ordinary graph reachability cannot
mistake satisfaction of one conjunct for satisfaction of all of them.

Here:

- \(V_t\) is the **target** marked surface;
- \(\Gamma_t\) is the target path, lamination, foliation, or WAD schema;
- \(\mathcal E_t\) is its complete target endpoint/base/crest record;
- \(\mathcal H_q\) is the analytic stage on which the query is made;
- `constructor` is one of restriction, covering pullback, pushforward,
  localization, WAD restriction, domination, Value, thick--thin, or
  Wanderers route formation;
- `universal query` records the quantifier over every target path required
  by KKL's definition of \(\iota^*X\);
- `filters` records, downstream, which geometric restrictions are ignored
  because they are not paths in the refined marking or are subordinate to
  a single pulled interval; and
- `last use` gives a theorem call which becomes ill-typed if the row is
  deleted.

### 4.3 Geometric restriction query

For every target path \(\gamma\), the restriction seed is
\[
  Z_{\iota,\gamma}:=\iota^{-1}(|\gamma|).
\tag{4.3}
\]
The finite ledger contains the universal binder
\[
 {\sf Rstr}_{\iota}[\Gamma]
 :=
 \bigl\{(\gamma,\gamma'):
   \gamma\in\Gamma,\ \gamma'\text{ source-proper},\
   |\gamma'|\subset\iota^{-1}(|\gamma|)\bigr\}
\tag{4.4}
\]
as one query token.  Semantically this query ranges over every proper
source path in the geometric trace before the KKL filters are applied;
it does not claim to enumerate those paths.  A parametrized fiber product
\[
  \{(t,z):\iota(z)=\gamma(t)\}
\]
is retained only as a subrecord.  This ordering is forced by
`PARAMETRIZED_PULLBACK_KKL_EXHAUSTION_NO_GO`.

### 4.4 Universal interval query

For every connected target ideal set \(X\) requested by a row, the ledger
records the full KKL query:

> Find the maximal \(\iota^*X\) such that, for every proper target path
> \(\gamma\), if the complete geometric restriction of \(\gamma\) has
> exactly one proper source-path component \(\gamma'\), and that component
> is subordinate to \(\iota^*X\), then \(\gamma\) is subordinate to \(X\):
> \[
> \bigl[(\exists!\,\gamma'\in\iota^*\gamma)
>       \land \gamma'\preceq\iota^*X\bigr]
> \Longrightarrow \gamma\preceq X.
> \]

The row records the query without assuming that the maximum exists, that
different pulled intervals are disjoint, or that the immersion is proper.
Those are later predicates.

## 5. Conditional finiteness for a supplied execution

### Definition 5.1 -- finite execution skeleton

An execution skeleton is
\[
  \mathsf H=(J,C,w),
\tag{5.1}
\]
where \(J\) is a finite set of actual proof-occurrence stages, including
every intermediate unit stage in a selected iterate; \(C\) is the finite
set of theorem-call occurrences; and \(w\) records every selected
return/critical word, degree word, and theorem alternative.  Every
constructor occurrence in the proof syntax must be attached to a named
element of \(J\) or \(C\).  Unrestricted recursive generation of new
stage terms is forbidden.

### Definition 5.2 -- certified binder-aware source package

A certified source package over \(\mathsf H\) is
\[
\mathfrak P=
(A,\operatorname{loc},\operatorname{kind},\operatorname{scope},
\beta,\tau,\operatorname{dep},S),
\tag{5.2}
\]
where:

1. \(A\) is a finite set of source occurrences after recursive input
   expansion and removal of inactive comments;
2. `loc` assigns a stable file-hash and byte-span identifier to each
   occurrence;
3. \(\beta\) binds every symbol use to one declaration or quantified
   binder, and \(\tau\) assigns its mathematical type;
4. every theorem invocation is a distinct occurrence with a callee and
   complete formal-to-actual substitution;
5. \(S\) contains every active theorem-call, target-family,
   ideal-interval, and universal KKL-subordination-query occurrence
   required by the frozen program; and
6. \(a\operatorname{dep}b\) means that \(a\) requires \(b\) for typing,
   construction, hypotheses, or justification.

Completeness of this input certificate requires classification of every
active reference, citation, prose invocation, target-family and interval
use, constructor operand, binder, and external-theorem boundary.

### Proposition 5.3 -- finite instantiated token universe

For a supplied finite skeleton \(\mathsf H\), the binder-aware token
universe \(X_{\mathsf H}\) generated by the row type of Section 4 is
finite.

#### Proof

The sets \(J\), \(C\), and the set of recorded words are finite by
definition.  Each named syntax occurrence has finite arity and requests a
finite list of typed subterms.  The only apparently infinite constructors
are geometric path families and universal restriction/subordination
queries; Section 4 encodes each such family as one intensional binder
token.  Recursion can add a token only at a named occurrence in \(J\cup C\).
Induction over the finite proof abstract-syntax tree therefore produces
finitely many tokens. \(\square\)

This proposition is deliberately conditional.  The KKL cap
\(216b^2\) would bound the number of critical-visit occurrences after the
interval-growth proof is repaired, but it does not itself select the
return words or repair the malformed fast-forward and Wanderers calls.
Consequently Proposition 5.3 cannot be used to assert that the project's
actual direct-decoration execution has already been constructed.

 Z^{gb}_{I,\geq m}

### Theorem 8.2: finite binder-ledger compiler

Let \(\mathsf H=(J,C,w)\) be a finite execution skeleton and let

  :={\rm Reach}_E(S_{\mathfrak P})
\tag{8.2}

#### Proof

### Theorem 8.4 -- fixed-skeleton syntactic final-root extension criterion

Let \(P\subset P'\) be two supplied root packages and let
\[
 e:X_{\mathsf H}(P)\longrightarrow X_{\mathsf H}(P')
\]
be an injective, sort-preserving graph embedding that sends old seeds to
new seeds and preserves every old dependency edge; equivalently,
\[
 e(S_P)\subseteq S_{P'},\qquad e(E_P)\subseteq E_{P'}.
\]
Then
\[
 e(L_{\rm syn}(P))\subseteq L_{\rm syn}(P').
\tag{8.4}
\]
Writing the new ledger's old-token slice as
\[
 L_{\rm old}(P')
 :=L_{\rm syn}(P')\cap e(X_{\mathsf H}(P)),
\]
one has
\[
 L_{\rm old}(P')=e(L_{\rm syn}(P))
\tag{8.5}
\]
exactly when no seed of \(P'\) reaches a token in
\(e(X_{\mathsf H}(P)\setminus L_{\rm syn}(P))\).

Moreover, the following are equivalent:

1. \(L_{\rm syn}(P')=e(L_{\rm syn}(P))\);
2. every seed of \(P'\) lies in \(e(L_{\rm syn}(P))\), and no dependency
   edge of the enlarged graph leaves \(e(L_{\rm syn}(P))\);
3. no directed path, including a path of length zero, from any enlarged
   seed reaches a vertex outside \(e(L_{\rm syn}(P))\); and
4. no SCC that is **not contained in**
   \(e(L_{\rm syn}(P))\) is reachable from an enlarged seed SCC.

#### Proof

The image under \(e\) of a path from an old seed is a path from a new
seed, proving (8.4).  If a new seed reaches an old omitted token, that
token enters the new ledger but not the old image, so equality fails.
The same is true if an old seed reaches the omitted token through a newly
added edge, which is why the criterion quantifies over **all** seeds of
\(P'\).  Conversely, if no seed reaches an old omitted token, every old
token in the new ledger already lies in the old image by the definition
of reachability.

For the full-ledger criterion, (2) makes the old image an admissible
closed ledger containing all enlarged seeds; leastness and (8.4) give
(1).  Statement (1) immediately implies (2).  A path leaves the old image
exactly when its first leaving edge does, proving the equivalence of (2)
and (3).  Reachability is constant on SCCs, so (3) and (4) are equivalent.
\(\square\)

This is only syntactic schema stability.  It says nothing about no-birth
of geometric inverse-trace components, proper paths, endpoints, accesses,
or WAD mass.  Those are PE-3--PE-5.
